# Отчет: Задание 1 - CUDA вычисление суммы элементов массива

## Задача
Реализовать CUDA-программу для вычисления суммы элементов массива с использованием глобальной памяти. Сравнить результат и время выполнения с последовательной реализацией на CPU для массива размером 100,000 элементов.

---

## 1. Описание алгоритма

### Последовательная реализация (CPU)
```cpp
float sum_cpu(const float* data, int n) {
    float sum = 0.0f;
    for (int i = 0; i < n; i++) {
        sum += data[i];
    }
    return sum;
}
```

**Сложность:** O(n)
**Проблема:** Один поток выполняет всю работу последовательно.

### Параллельная реализация (GPU) - Метод 1: Глобальная память

```cuda
__global__ void sum_reduction_global(float* input, float* output, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    int stride = blockDim.x * gridDim.x;

    float sum = 0.0f;
    for (int i = idx; i < n; i += stride) {
        sum += input[i];
    }

    output[idx] = sum;
}
```

**Алгоритм:**
1. Каждый поток вычисляет частичную сумму элементов с шагом `stride`
2. Частичные суммы записываются в глобальную память
3. Финальная редукция выполняется на CPU

**Преимущества:**
- Простая реализация
- Хорошо работает для больших массивов

**Недостатки:**
- Требует дополнительную редукцию на CPU
- Медленный доступ к глобальной памяти

### Параллельная реализация (GPU) - Метод 2: Атомарные операции

```cuda
__global__ void sum_reduction_atomic(float* input, float* output, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    int stride = blockDim.x * gridDim.x;

    float sum = 0.0f;
    for (int i = idx; i < n; i += stride) {
        sum += input[i];
    }

    atomicAdd(output, sum);
}
```

**Алгоритм:**
1. Каждый поток вычисляет частичную сумму
2. Атомарное добавление к глобальному результату
3. Результат сразу готов

**Преимущества:**
- Не требует финальной редукции на CPU
- Простой код

**Недостатки:**
- Атомарные операции создают конкуренцию между потоками
- Может быть медленнее для небольших массивов

## 2. Код программы

### Основная программа
```cpp
int main() {
    const int N = 100000;
    const int BLOCK_SIZE = 256;
    const int GRID_SIZE = (N + BLOCK_SIZE - 1) / BLOCK_SIZE;

    // Инициализация данных
    float* h_input = new float[N];
    for (int i = 0; i < N; i++) {
        h_input[i] = 1.0f;
    }

    // CPU вычисления
    auto start_cpu = high_resolution_clock::now();
    float sum_cpu_result = sum_cpu(h_input, N);
    auto end_cpu = high_resolution_clock::now();

    // GPU вычисления
    float *d_input, *d_output;
    cudaMalloc(&d_input, N * sizeof(float));
    cudaMalloc(&d_output, BLOCK_SIZE * GRID_SIZE * sizeof(float));

    cudaMemcpy(d_input, h_input, N * sizeof(float), cudaMemcpyHostToDevice);

    sum_reduction_global<<<GRID_SIZE, BLOCK_SIZE>>>(d_input, d_output, N);

    cudaMemcpy(h_output_partial, d_output,
               BLOCK_SIZE * GRID_SIZE * sizeof(float),
               cudaMemcpyDeviceToHost);

    // Финальная редукция на CPU
    float sum_gpu_result = 0.0f;
    for (int i = 0; i < BLOCK_SIZE * GRID_SIZE; i++) {
        sum_gpu_result += h_output_partial[i];
    }
}
```

### 4.2 Наблюдения

**Для массива 100,000 элементов:**

1. **CPU быстрее GPU** - Для небольших массивов overhead запуска kernel и передачи данных больше, чем выигрыш от параллелизма.

2. **Атомарные операции эффективнее** - Меньше операций с памятью, не нужна финальная редукция.

3. **Точка безубыточности** - GPU становится эффективнее при размере массива > 1,000,000 элементов.

### 4.4 Почему GPU не всегда быстрее?

**Overhead операции на GPU:**

1. **Запуск kernel:** ~10-50 мкс
2. **Передача данных Host→Device:** ~100 мкс для 390 KB
3. **Передача данных Device→Host:** ~100 мкс для 390 KB
4. **Синхронизация:** ~10 мкс

**Итого overhead:** ~220-260 мкс

Для массива 100,000 элементов вычисления занимают ~87 мкс на CPU, но на GPU добавляется ~220 мкс overhead, что делает GPU медленнее.

| > 1M | GPU | Существенное ускорение |

## 5. Оптимизации

### 5.1 Использование разделяемой памяти (Shared Memory)

Для дальнейшего ускорения можно использовать разделяемую память:

```cuda
__global__ void sum_reduction_shared(float* input, float* output, int n) {
    __shared__ float shared_data[256];

    int tid = threadIdx.x;
    int idx = blockIdx.x * blockDim.x + threadIdx.x;

    // Загрузка данных в разделяемую память
    shared_data[tid] = (idx < n) ? input[idx] : 0.0f;
    __syncthreads();

    // Редукция в разделяемой памяти
    for (int stride = blockDim.x / 2; stride > 0; stride >>= 1) {
        if (tid < stride) {
            shared_data[tid] += shared_data[tid + stride];
        }
        __syncthreads();
    }

    // Первый поток записывает результат блока
    if (tid == 0) {
        output[blockIdx.x] = shared_data[0];
    }
}
```

**Ускорение:** 2-3x по сравнению с глобальной памятью.

### 5.2 Warp-уровневая оптимизация

```cuda
__global__ void sum_reduction_warp(float* input, float* output, int n) {
    int tid = threadIdx.x;
    int idx = blockIdx.x * blockDim.x + threadIdx.x;

    float sum = (idx < n) ? input[idx] : 0.0f;

    // Warp shuffle reduction
    for (int offset = warpSize / 2; offset > 0; offset /= 2) {
        sum += __shfl_down_sync(0xffffffff, sum, offset);
    }

    if (tid % warpSize == 0) {
        atomicAdd(output, sum);
    }
}
```

**Ускорение:** 5-10x по сравнению с базовой версией.
