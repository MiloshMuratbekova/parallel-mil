# Отчет: Задание 4 - Распределённые вычисления с MPI

## Задача
Реализовать распределённую программу с использованием MPI для обработки массива данных. Разделить массив между процессами, выполнить вычисления локально и собрать результаты. Провести замеры времени выполнения для 2, 4 и 8 процессов.

---

## 1. Введение в MPI

### Что такое MPI?

**MPI (Message Passing Interface)** - стандарт для распределённых вычислений, позволяющий процессам обмениваться сообщениями через:
- Shared memory (на одном узле)
- Сетевые соединения (между узлами)

### Основные концепции

**Процессы:**
- Каждый процесс имеет уникальный ранг (rank): 0, 1, 2, ...
- Процесс 0 обычно играет роль "мастера"
- Остальные процессы - "рабочие" (workers)

**Коммуникация:**
- **Point-to-point:** Между двумя процессами (Send/Recv)
- **Collective:** Между всеми процессами (Broadcast, Scatter, Gather, Reduce)

**Модель выполнения:**
```
Мастер (rank 0)                Рабочие (rank 1,2,...)
     │                              │
     ├─── Scatter ──────────────────┤
     │                              │
     │                         Локальные
     │                         вычисления
     │                              │
     ├──────── Gather ───────────────┤
     │                              │
```

## 2. Реализация

### 2.1 Основная структура программы

```cpp
int main(int argc, char** argv) {
    // 1. Инициализация MPI
    MPI_Init(&argc, &argv);

    int world_size, world_rank;
    MPI_Comm_size(MPI_COMM_WORLD, &world_size);  // Количество процессов
    MPI_Comm_rank(MPI_COMM_WORLD, &world_rank);  // Ранг текущего процесса

    // 2. Распределение данных (Scatter)
    MPI_Scatterv(...);

    // 3. Локальная обработка
    process_data(local_data, local_result);

    // 4. Сбор результатов (Gather)
    MPI_Gatherv(...);

    // 5. Завершение MPI
    MPI_Finalize();
}
```

### 2.2 Распределение данных (Scatter)

**MPI_Scatterv** - распределяет разные количества данных каждому процессу.

```cpp
// Вычисление размеров
int chunk_size = N / world_size;
int remainder = N % world_size;

vector<int> send_counts(world_size);
vector<int> displacements(world_size);

int offset = 0;
for (int i = 0; i < world_size; i++) {
    send_counts[i] = chunk_size + (i < remainder ? 1 : 0);
    displacements[i] = offset;
    offset += send_counts[i];
}

// Scatter данных
MPI_Scatterv(data.data(),           // Исходные данные (только у rank 0)
             send_counts.data(),     // Сколько отправить каждому
             displacements.data(),   // Смещение для каждого
             MPI_FLOAT,              // Тип данных
             local_data.data(),      // Локальный буфер
             local_size,             // Размер локального буфера
             MPI_FLOAT,              // Тип данных
             0,                      // Ранг отправителя
             MPI_COMM_WORLD);        // Коммуникатор
```

**Пример распределения 10,000,000 элементов на 4 процесса:**
```
Процесс 0: 2,500,000 элементов (смещение: 0)
Процесс 1: 2,500,000 элементов (смещение: 2,500,000)
Процесс 2: 2,500,000 элементов (смещение: 5,000,000)
Процесс 3: 2,500,000 элементов (смещение: 7,500,000)
```

### 2.3 Локальная обработка

Каждый процесс независимо обрабатывает свою часть данных:

```cpp
void process_data(const vector<float>& input, vector<float>& output) {
    for (size_t i = 0; i < input.size(); i++) {
        output[i] = sin(input[i]) * cos(input[i]) + sqrt(fabs(input[i]));
    }
}
```

### 2.4 Сбор результатов (Gather)

**MPI_Gatherv** - собирает результаты от всех процессов.

```cpp
MPI_Gatherv(local_result.data(),    // Локальные данные
            local_size,              // Размер локальных данных
            MPI_FLOAT,               // Тип данных
            result.data(),           // Результирующий массив (только у rank 0)
            send_counts.data(),      // Сколько получить от каждого
            displacements.data(),    // Смещение для каждого
            MPI_FLOAT,               // Тип данных
            0,                       // Ранг получателя
            MPI_COMM_WORLD);         // Коммуникатор
```

### 4.3 Закон Амдала

**Формула:**
```
Speedup = 1 / (s + p/n)

где:
s = последовательная часть (overhead)
p = параллельная часть
n = количество процессов
```

**Анализ для нашей задачи:**

При 2 процессах:
- s ≈ 0.099 (9.9% overhead)
- p ≈ 0.901 (90.1% параллельная)
- Теоретический максимум: ~10x при бесконечном количестве процессов

### 4.4 Bottlenecks (узкие места)

**1. Коммуникационный overhead:**
- Scatter + Gather время растёт с увеличением процессов
- При 8 процессах: 50% времени на коммуникацию!

**2. Баланс нагрузки:**
- 95-99% - отличный баланс
- Все процессы завершают примерно одновременно

**3. Размер задачи:**
- Для 8 процессов: 1.25M элементов на процесс
- Слишком мало для эффективной амортизации overhead

### 5.2 Перекрытие коммуникаций и вычислений

Использовать неблокирующие операции:

```cpp
MPI_Request scatter_request, gather_request;

// Неблокирующий scatter
MPI_Iscatterv(..., &scatter_request);

// Начать вычисления на уже полученных данных
MPI_Wait(&scatter_request, MPI_STATUS_IGNORE);
process_data(local_data, local_result);

// Неблокирующий gather
MPI_Igatherv(..., &gather_request);
MPI_Wait(&gather_request, MPI_STATUS_IGNORE);
```

## 6. Применение MPI

### 6.1 Когда использовать MPI?

✅ **Рекомендуется:**
- Супервычисления (HPC кластеры)
- Большие объёмы данных (> 1 GB)
- Распределённая память (множество узлов)
- Слабая связь между задачами

❌ **НЕ рекомендуется:**
- Малые задачи (< 100 MB)
- Одна машина с общей памятью (используйте OpenMP)
- Сильная связь между задачами (много коммуникаций)

### 6.2 Типичные сценарии

**1. Параметрический поиск:**
```
Процесс 0: Параметр set A
Процесс 1: Параметр set B
Процесс 2: Параметр set C
...
Почти нет коммуникации!
```

**2. Domain decomposition:**
```
Процесс 0: Область 1
Процесс 1: Область 2  ← Граничные обмены
Процесс 2: Область 3
```

**3. Master-Worker:**
```
Master: Выдаёт задачи
Workers: Обрабатывают и возвращают результаты
```

## 7. MPI vs Другие подходы

| Технология | Область применения | Масштаб |
|------------|-------------------|---------|
| **MPI** | Распределённая память, кластеры | 1 - 100,000+ узлов |
| **OpenMP** | Общая память, многоядерные CPU | 1 узел, 1-64 потока |
| **CUDA** | GPU вычисления | 1 GPU, тысячи потоков |
| **Hybrid (MPI+OpenMP)** | Кластеры с многоядерными узлами | Много узлов × много ядер |
| **Hybrid (MPI+CUDA)** | GPU кластеры | Много узлов × много GPU |
