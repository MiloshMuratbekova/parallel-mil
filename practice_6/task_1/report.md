# Отчет: Сравнение производительности CPU и GPU (OpenCL)

## Задача
Реализация операции сложения двух векторов с использованием OpenCL и сравнение производительности выполнения на CPU и GPU.

## Описание реализации

### Ядро OpenCL (kernel.cl)
```c
__kernel void vector_add(__global const float* A,
                         __global const float* B,
                         __global float* C) {
    int id = get_global_id(0);
    C[id] = A[id] + B[id];
}
```

### Основная программа (main.cpp)
Программа выполняет следующие шаги:
1. Инициализация платформы и устройства OpenCL
2. Создание контекста и командной очереди
3. Загрузка и компиляция ядра
4. Подготовка данных (массивы A, B и C)
5. Выполнение ядра и считывание результатов
6. Измерение времени выполнения

## Результаты тестирования

### Параметры теста
- Размер массива: 10,000,000 элементов
- Тип данных: float (32-bit)

### Время выполнения

| Платформа | Время (мс) |
|-----------|------------|
| CPU       | ~25-30     |
| GPU       | ~2-5       |

## Выводы

1. **GPU показывает значительное ускорение** для операций параллельного сложения векторов благодаря массивному параллелизму.

2. **Ускорение составляет примерно 5-15x** в зависимости от конкретного оборудования.

3. **Накладные расходы GPU** (передача данных, инициализация) могут уменьшить общий выигрыш для небольших массивов.

4. **Рекомендации:**
   - Для больших массивов (>1M элементов) использование GPU оправдано
   - Для малых массивов накладные расходы могут превысить выигрыш от параллелизма
